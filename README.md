# ghostty-dotfiles
Ghostty is a fast, native terminal emulator with a focus on performance and simplicity. This repo contains my personal Ghostty configuration and dotfiles.

## Installation
! Install the ghostty terminal for your Linux distro and then proceed with the following steps.

1. **Clone this repository**:

```bash
git clone https://github.com/tudorioan1/ghostty-dotfiles.git
```
2.  **Go to the directory**:
   ```
cd ghostty-dotfiles
```
3. **Copy the configuration file to your Ghostty config directory**:
```
cp -r ghostty ~/.config/ghostty
```
Restart ghostty and enjoy!
Feel free to make modifications to it, my config is made for a tiling window manager so you might not have a bar with the navigation buttons.
! You might need to install the MesloLGM Nerd Font.
